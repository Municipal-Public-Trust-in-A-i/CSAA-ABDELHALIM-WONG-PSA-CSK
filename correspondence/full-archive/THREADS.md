# Thread groups

> **This page is not a filing.** It is not new service. It does not restart any Code of Civil Procedure section 128.7 clock. Publishing is not service.

The Phase 1 export contains **187 messages** across **75 email threads**. Listing them by thread alone would not tell a reader much, so the threads are collected below into nine chronological groups. Each group opens with one paragraph explaining what that stretch of correspondence is about; the threads and messages follow, with every message linked.

Direction and speech attribution are marked on every row and on every message page. **O** is outbound Rosario speech, **I** is inbound defense speech, and **C** is court-staff mail, which is never Rosario speech. Threads marked court-seen were lodged as exhibits for the August 26, 2026 section 391 hearing and publish unredacted, matching the filed exhibit, with tone left exactly as lodged.

Flat listings by folder: [outbound](outbound/INDEX.md) · [inbound](inbound/INDEX.md) · [court-staff](court-staff/INDEX.md). Exhibit mapping: [CHALLENGED-SET.md](CHALLENGED-SET.md) · [UNREDACTED-COURT-SEEN.md](UNREDACTED-COURT-SEEN.md).
