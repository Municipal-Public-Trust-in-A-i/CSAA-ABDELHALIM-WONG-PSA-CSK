## What this folder is

This directory publishes the **latest consolidated opposition materials** matching the rebuilt draft structure: **five filed-style opposition volumes plus one lodged bench binder**, with redundant standalone “smoking-gun preamble” fragments removed from multiple instruments and folded into the principal memoranda where appropriate.

**Strategic framing:** The opposition memoranda carry a shared **§I.A — “Smoking-Gun” Preamble** block (court reliance on defense representations, rulings procured from that reliance, and the Trial Day 7 admission), so the gravamen narrative appears once per core filing rather than repeated across many exhibits.
